# component

## 1. Main Controller
-ESP32 DevKit V1 (30 Pin) ×1
-Kaam: WiFi, sensor reading, backend se communication.

## 2. Authentication
- RFID RC522 Module ×1
- RFID Cards/Tags ×2–4
-Kaam: User authentication.

## 3. Charging Ports
- Dummy EV Charging Connector ×2
(Ya 2 female DC sockets demo ke liye use kar sakte ho.)

## 4. Charging Control
- 2-Channel Relay Module ×1
-Kaam: Charger 1 aur Charger 2 ON/OFF.

## 5. Current Monitoring
- ACS712 Current Sensor ×2
-Kaam: Dono charging ports ka current monitor karega.

## 6. Voltage Monitoring 
- Voltage Sensor Module ×2 (Optional but recommended)
-Kaam: Charging voltage monitor karna.

## 7. Display
- 0.96" OLED Display (I2C) ×1

-Display karega:User ID
               Charger Status
               AI Suggestion
               
## 8. Indicators
- Green LED ×2
- Red LED ×2
- Buzzer ×1
-Kaam:Green = Charging
     Red = Busy/Fault
     Buzzer = RFID scan ya error
     
## 9. Temperature Monitoring
- DS18B20 ya DHT22 ×1 (Optional)
-Kaam: Overheating detect karna.

## 10. Power Supply
- 5V Adapter
- USB Cable for ESP32

## 11. Wiring
-Breadboard
-Jumper Wires
-PCB (final prototype ke liye)
